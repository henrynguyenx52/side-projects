# AI Watermark Cleaner (Isolated Workspace)

Thư mục độc lập chứa toàn bộ `.venv` và model cache (`.cache/`) để dễ dàng xoá sạch khi không dùng nữa.

## Chạy lệnh
```bash
./run.sh video identify /path/to/video.mp4
./run.sh video invisible /path/to/video.mp4 -o output/clean.mp4
```

## Dọn dẹp hoàn toàn
```bash
rm -rf /Users/hungnguyen/Documents/side-projects/ai-watermark-cleaner
```
