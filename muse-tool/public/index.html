Cài đặt Trình duyệt Playwright

Tài liệu OpenAI-Compatible API

Địa chỉ Endpoint máy chủ: http://localhost:18638/v1

1. Tạo Video qua API

curl -X POST http://localhost:18638/v1/videos \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Cô gái năng động tập thể dục buổi sáng trong công viên",
    "duration": "20s",
    "aspect_ratio": "9:16",
    "quality": "4K"
  }'

2. Tạo Hình ảnh (DALL-E 3 Compatible)

curl -X POST http://localhost:18638/v1/images/generations \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Chai nước hoa cao cấp đặt trên phiến đá cẩm thạch đen",
    "size": "1080x1920"
  }'

3. Chat / Hoàn thành văn bản (Chat Completions)

curl -X POST http://localhost:18638/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "muse-spark",
    "messages": [{"role": "user", "content": "Viết kịch bản ngắn giới thiệu quán cafe acoustic"}]
  }'
